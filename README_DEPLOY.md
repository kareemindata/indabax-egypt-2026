# IndabaX Egypt 2026 — Program Review Workspace

This folder is safe to push to GitHub Pages. It contains only the static frontend.

## Deploy

1. Edit `assets/config.js` with the Supabase project URL and anon/publishable key.
2. Push these files to the GitHub Pages branch/repository.
3. Share the workspace link and the appropriate access code.

## Optional link format

You can prefill an access code using:

`index.html?code=ACCESS_CODE_HERE`

Named access can also prefill a name:

`index.html?name=NAME&code=ACCESS_CODE_HERE`
